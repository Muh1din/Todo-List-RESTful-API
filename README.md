# Todo List RESTful API

A learning project to explore full-stack web development using Java, Spring Boot, and Vue.js, with a focus on RESTful API development.

## Tech Stack
- **Backend:** Java 21, Spring Boot
- **Frontend:** HTML, Tailwind CSS, JavaScript, Vue.js
- **Database:** MySQL

## Purpose
This project is built to learn and practice:

- Java programming.
- Spring Boot development.
- RESTful API implementation.
- Database integration.
- Frontend and backend integration.
